## 1. 📌 미션 요구사항 (Requirements)

`useState`훅을 사용해서 상태를 정의해보세요

1. name(string)에 해당하는 상태를 정의합니다.
2. age(number)에 해당하는 상태를 정의합니다.
3. gender(male, female)에 해당하는 상태를 정의합니다.
4. name, age, gender를 화면에 렌더링합니다.
5. "Update Profile" 버튼을 만들어서 클릭시에 name, age, gender를 임의의 다른 값으로 변경해보세요.

- 초기값
- name: "Jack"
- age: 20
- gender: "male"
  <br />
- 변경값
- name: "John"
- age: 30
- gender: "female"
