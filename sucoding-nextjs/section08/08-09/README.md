## 💡 핵심 학습 내용 (Key Concepts)

### 1. [개념]

Next.js는 특정 라우트를 빌드 시점에 미리 렌더링하고 그 결과를 저장한다. 이렇게 생성된 HTML과 RSC 페이로드를 캐싱해두는 메커니즘을 풀 라우트 캐시라고 한다.

이러한 기능 덕분에 매번 서버 렌더링을 다시 수행하지 않아도 되기 때문에 페이지 로드 속도를 크게 향상시킬 수 있다.

또한 풀 라우트 캐시는 `개발 모드`에서는 동작하지 않는 캐시라는 점이다. 이는 빌드 결과를 기반으로 생성되는 캐시이기 떄문이다. 따라서 빌드 시점에 생성되는 캐시라 이해하면 된다.

빌드 과정에서 특정 라우트가 정적으로 생성 가능하다고 판단되면 Next.js는 해당 라우트에 대해 React 서버 컴포넌트 트리를 서버에서 실행하고 클라이언트로 전달할 RSC 페이로드를 생성하는 단계에 들어간다.
