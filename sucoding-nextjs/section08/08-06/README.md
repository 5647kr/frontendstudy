# 📌 [Request Memoization - 1 (이론)]

> **한 줄 요약**: 

---

## 💡 핵심 학습 내용 (Key Concepts)

### 1. [개념]

하나의 렌더링 요청 안에서 동일한 비동기 작업을 한 번만 실행하고 그 결과를 재사용하는 매커니즘을 가지고 있는 캐싱 시스템이다. 데이터 캐시 보다 먼저 실행된다.

### 2. [Request Memoization 방식]

하나의 HTTP 요청을 처리하는 동안 발생하는 렌더링 흐름에서만 동작하는 캐싱 시스템이다.
즉, 하나의 요청에 대한 렌더링이 종료되면 캐시된 저장 데이터는 자동으로 삭제가 되게 된다.
