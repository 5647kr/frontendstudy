# 📌 [Next.js의 캐싱 전략 4가지]

> **한 줄 요약**: 캐싱 전략의 4가지

---

## 💡 핵심 학습 내용 (Key Concepts)

### 1. [캐싱이란]

웹 애플리케이션의 성능을 개선하고 로딩 속도를 높이기 위해 데이터를 저장하고 재사용하는 기술을 의미한다.
nextjs는 총 4가지의 캐싱 메커니즘을 가지고 있다.

클라이언트에서 처리하는 `Router Cache`, 서버에서 처리하는 `Full Route Cache, Request Memoization, Data Cache`가 있다.

### 2. [가정]

사용자가 /a라는 경로에 접속한다고 가정한다.

1. 먼저 클라이언트의 Router Cache를 확인한다. 만약 캐시된 데이터가 없으면 서버로 요청이 전달된다.
2. 서버로 요청이 전달되면 Full Router Cache를 확인한다. 만약 캐시된 데이터가 없으면 렌더링 프로세스가 시작된다.
3. 이때 Request Memoization 계층이 동작하여 렌더링 중 중복 요청을 방지하게 된다.
4. 실제 데이터가 필요한 시점에 Data Cache를 거쳐 데이터베이스와 같은 데이터 소스에서 데이터를 가져온다.

각 과정에서 독립적으로 캐시 데이터를 저장한다.
