## 💡 핵심 학습 내용 (Key Concepts)

### 1. [데이터 캐시]

Data Cache는 Nextjs의 fetch API와 밀접하게 관련된 캐싱 메커니즘이다.

Fetch API는 원래 클라이언트 전용이었던 WEB API를 Nextjs 팀이 확장하여 서버에서도 사용 가능하도록 만들었다.

서버 컴포넌트에서 fetch API 사용시 클라이언트 컴포넌트에서 사용했던 것과 같이 아래와 같이 구성된다.

```
fetch(주소, 옵션)
```

### 2. [캐시 옵션]

위 fetch 에 더해 서버 컴포넌트에서는 캐싱을 제어할 수 있는 캐시 옵션을 추가로 사용할 수 있다.

```
fetch(주소, {cache: "force-cache" | "no-store"});
```

- force-cache: 캐시를 사용한다.
- no-store: 캐시를 사용하지 않는다.

두 옵션 중 하나를 선택해 사용한다.

no-store로 설정할 경우 데이터베이스까지 매번 데이터를 요청한다.
만약 forch-cache로 설정할 경우 데이터베이스에 데이터를 요청하고 그 결과를 data cache에 json 형식으로 저장하게 된다. 그 이후엔 데이터를 요청하면 데이터베이스까지 요청하는 것이 아닌 data cache에 있는 데이터를 반환한다.
