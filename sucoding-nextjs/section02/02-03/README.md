## 1. 서버 컴포넌트와 클라이언트 컴포넌트

부모 서버 컴포넌트    서버 컴포넌트
 |     가능          가능
자식 서버 컴포넌트    클라이언트 컴포넌트
 |     가능          불가능
자손 클라이언트      서버 컴포넌트


만약 클라이언트 컴포넌트의 자식 컴포넌트로 서버 컴포넌트가 왔을 때, 서버 코드가 단 한줄도 없으면
서버컴포넌트는 서버 컴포넌트가 아닌 클라이언트 컴포넌트 취급이 된다.
