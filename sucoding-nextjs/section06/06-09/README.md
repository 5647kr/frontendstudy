# 미션 01: JSONPlaceholder 게시글 5개 목록 + 좋아요/뷰 카운트

## 1. 미션 소개

이번 미션에서는 이미 퍼블리싱이 완료된 **블로그 카드 디자인**에  
`JSONPlaceholder`의 게시글 데이터를 붙이고,  
각 카드에 **랜덤 좋아요 / 뷰 카운트 + 좋아요 버튼 인터랙션**을 구현합니다.

아래의 형태의 카드 디자인이 **적용된 초기 프로젝트가 준비되어** 있습니다.  
(npm install -> npm run dev)

<img src="./public/image.png" alt="이미지" width="500">

카드의 구성 요소는 다음과 같습니다.

- 상단: User 정보, Post 번호
- 제목, 본문 내용
- 하단: ❤️ 아이콘 + 좋아요 개수, 👁 아이콘 + 조회수
- 그 아래에 “댓글 보기” 영역의 퍼블리싱이 있으나,  
  **이번 미션에서는 댓글 영역은 전혀 건드리지 않습니다.**

## 2. 목표 기능 정리

1. `JSONPlaceholder`의 **posts API**를 사용해 **게시글 5개만** 가져와서 렌더링한다.
2. 각 게시글 카드에
   - 랜덤 좋아요 수
   - 랜덤 조회수(뷰 카운트)
     를 초기값으로 보여준다.
3. 좋아요 아이콘(또는 버튼)을 클릭하면
   - 좋아요 숫자가 **1 증가**한다.
   - 다시 클릭하면 **1 감소**한다.
   - 실제 서버에 요청이 나가는 것처럼 **약 0.3초의 지연 시간**을 인위적으로 준다.
4. 댓글 영역은 퍼블리싱만 존재하고, **이번 미션에서는 어떤 로직도 추가하지 않는다.**

## 3. 사용할 API

### 3-1. 게시글 목록 API

- 엔드포인트 예시:
  ```txt
  https://jsonplaceholder.typicode.com/posts?_limit=5
  ```
- 주요 필드
  - id: 게시글 ID
  - userId: 작성자 ID
  - title: 제목
  - body: 내용

## 4. 구현 요구 사항

### 4-1. 게시글 5개 렌더링

- 블로그 메인 페이지에서 posts API를 호출해 5개의 게시글을 가져옵니다.
- 응답으로 받은 데이터를 기본으로 제공된 카드 디자인에 맞춰 렌더링합니다.
  - 제목: title
  - 내용: body (전체 또는 앞부분만 잘라서 사용 가능)
  - 상단의 User 정보, Post 번호 영역에 userId, id 등을 적절히 매핑합니다.

> 퍼블리싱 구조(HTML/Tailwind 등)는 최대한 유지하고,
> 데이터 바인딩 부분만 채우는 것에 집중하세요.

### 4-2. 랜덤 좋아요 / 뷰 카운트 초기값 설정

각 게시글 카드마다 다음과 같이 초기값을 설정합니다.

- 좋아요 수: 예) 0 ~ 50 사이의 랜덤 정수
- 조회수(뷰 카운트): 예) 0 ~ 1000 사이의 랜덤 정수

```tsx
const randomLikes = Math.floor(Math.random() * 51); // 0~50
const randomViews = Math.floor(Math.random() * 1001); // 0~1000
```

- 각 게시글마다 서로 다른 랜덤값을 가지도록 해야 합니다.

### 4-3. 좋아요 버튼 인터랙션

1. 좋아요 아이콘 또는 버튼을 클릭하면:
   - 바로 숫자가 증가하는 것이 아니라,
   - 0.3초 동안 지연 상태였다가 숫자가 1 증가합니다.
2. 이때 실제 API 요청은 보내지 않고,
   내부 상태로만 관리합니다. (로컬 state)
3. 지연 시간은 예를 들어 다음과 같이 구현할 수 있습니다.

```tsx
await new Promise((resolve) => setTimeout(resolve, 300));
```

4. 지연 중에는 ..
   - 버튼을 비활성화하는 등의 피드백을 주면 더 좋습니다. (선택)

5. 이미 클릭한 좋아요를 다시 클릭하면 숫자가 1 감소합니다.

### 4-4. 댓글 영역은 건드리지 않기

- 카드 하단에 있는 **댓글 관련 영역(“댓글 보기”, 댓글 내용 박스 등)**은  
  이미 마크업/스타일이 되어 있지만,  
  이번 미션에서는 어떠한 기능도 구현하지 않습니다.  
  클릭 이벤트, 데이터 패칭, 상태 관리는 모두 다음 미션에서 다룰 예정이라고 생각하고,  
  지금은 그대로 두세요.
