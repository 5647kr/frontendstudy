## 💡 핵심 학습 내용 (Key Concepts)

### 1. [동작 순서]

1. 클라이언트가 웹페이지에 접속한다. 이때는 아직 빈 페이지이다.
2. 클라이언트는 nextjs 서버로 경로에 대한 페이지 요청을 보낸다.
3. nextjs 서버는 요청받은 경로에 해당하는 서버 컴포넌트를 찾는다.
4. 서버 컴포넌트를 찾으면 렌더링 과정을 거치게 된다.
5. 렌더링 과정은 재귀적으로 비동기적으로 이루어진다.
6. 이때 클라이언트 컴포넌트를 만나게 되면 지시사항을 준비한다.
7. 또한 시간이 걸리는 서버 컴포넌트를 만나게 되면 일단 fallback으로 설정한 UI를 보여주고 실제 컴포넌트는 병렬로 실행한다.
8. 이렇게 완성된 컴포넌트를 특별한 형식으로 직렬화한 데이터이다.
9. 데이터를 기반으로 nextjs는 html 파일을 생성한다.(이는 상호작용이 없는 html파일이다.)
10. 완벽한 페이지는 아니지만 페이지의 전체적인 구조는 보이게 된다.
11. 시간이 걸리는 서버 컴포넌트를 생성하기 시작하는데 이 과정을 모든 서버컴포넌트을 반복적으로 수행한다.
12. 이후 점진적으로 완성된 컴포넌트부터 보이게 된다.
13. 완성한다.
