## 💡 핵심 학습 내용 (Key Concepts)

### 1. [개념]

React Server Component(RSC)는 새로운 컴포넌트를 설계하는 방법이다.

- 서버컴포넌트: 서버 컴포넌트에서만 실행되는 컴포넌트이다.
- 클라이언트 컴포넌트: 기본적으로 사용하던 React 컴포넌트와 동일하다.

### 2. [서버 컴포넌트의 특징]

장점

1. 서버 리소스에 직접 접근할 수 있다.
2. 큰 라이브러리를 안전하게 사용할 수 있다.
3. 자동으로 코드 스플리팅이 된다.
4. 보안이 강화된다.
5. 데이터 패칭이 간단해진다.

단점

1. 리액트 훅을 사용할 수 없다.
2. 브라우저 API를 사용할 수 없다.
3. 사용자 인터렉션을 처리할 수 없다.
