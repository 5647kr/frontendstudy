## 1. 설치 방법

1. npx create-next-app@latest .<br />
2. customize settings 선택한다. 한번 설치를 한 이후엔 reuse previous settings 선택 <br />
3. Would you like to use TypeScript? `Yes`<br />
4. Which linter would you like to use? `ESLint` <br />
5. Would you like to use React Compiler? `Yes` <br />
6. Would you like to use Tailwind CSS? `Yes` <br />
7. Would you like your code inside a src/ directory? `Yes` <br />
8. Would you like to use App Router? (recommended) `Yes` <br />
9. Would you like to customize the import alias (@/* by default)? `No` <br />
10. Would you like to include AGENTS.md to guide coding agents to write up-to-date Next.js code? `No` <br />
11. npm run dev
