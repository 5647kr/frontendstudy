# 📌 [메타 데이터 설정하기 3 (generateMetadata)]

> **한 줄 요약**: 완전 독립적인 404 페이지를 만들고 싶을 때 `global-not-found.tsx`를 생성하고 `html, body`태그를 사용해 작성하면 된다.

---

## 💡 핵심 학습 내용 (Key Concepts)

### 1. [개념]

generateMeta 함수를 사용하면 비동기 요청의 결과의 결과나 라우트 값 등을 기반으로 메타데이터를 동적으로 생성할 수 있다.

## 2. [적용 방법]

기존 RootLayout에 있는 metadata와 같이 작성하면 된다. 함수 안에 메타데이터 속성을 return 해주고 타입은 Metadata로 지정한다.

```
export function generateMetadata(): Metadata {
  return {
    title: "Create Next App",
    description: "Generated by create next app",
  };
}
```

## 3. [동적 메타데이터 적용하기]

post/[id]/page.tsx 파일을 생성해 동적 세그먼트를 생성해서 브라우저 제목에서 id를 포함하고 싶을 경우 generateMetadata를 사용한다.

- page.tsx에 generateMetadata를 지정한다
- params를 받는것과 마찬가지로 코드를 작성한다.
- Metadata의 타입을 Promise<Metadata>로 수정한다.

```
export async function generateMetadata({
  params,
}: {
  params: Promise<{ id: string }>;
}): Promise<Metadata> {
  const { id } = await params;
  return {
    title: `${id}번째 게시글 입니다.`,
    description: "Generated by create next app",
  };
}
```
